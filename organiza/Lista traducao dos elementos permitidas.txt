📌 1. ESCOPO E LIMITES
Table
Copy
Item	O que NÃO pode ser alterado	Motivo
Tags HTML	<body>, <header>, <nav>, <div>…	Palavras-chave da linguagem
Atributos HTML	id, class, href, src, alt, for, disabled…	Definidos pela especificação
Atributos data-*	data-livro, data-capitulo, data-letra	Padrão HTML5 – quebra se alterado
Palavras-chave JS	class, function, async, await, let, const, if, else	Sintaxe fixa
APIs do navegador	document, window, localStorage, console, fetch, URLSearchParams	Globais fixas
Métodos e propriedades	.getElementById(), .querySelector(), .addEventListener(), .textContent…	Comandos fixos
Eventos	click, change, input, DOMContentLoaded	Nomes de eventos padrão
Propriedades CSS	background-color, font-size, margin-left, display, position	Sintaxe da linguagem
Pseudo-classes / elementos	:hover, :disabled, ::before, ::after, ::-webkit-scrollbar	Seletores fixos
Nomes de arquivos	versoes.js, concordancia.css, index.html	Referência em scripts/links
